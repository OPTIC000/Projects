
# Диаграмма деятельности: Регистрация пользователя на сайте
## Краткое описание процесса
Процесс регистрации начинается с заполнения пользователем формы (имя, email, пароль). Система проверяет уникальность email. Если email уже занят — процесс завершается ошибкой. Если свободен — данные сохраняются, после чего параллельно запускаются: 1) отправка письма с ссылкой для подтверждения, 2) таймер ожидания (например, 24 часа). Затем система ожидает перехода по ссылке. Если подтверждение выполнено в срок — аккаунт активируется. Если нет — запись удаляется.
# Описание ключевых шагов
| № | Шаг | Пояснение |
|---|-----|-----------|
| 1 | Заполнение формы регистрации | Пользователь вводит имя, email и пароль. |
| 2 | Проверка уникальности email | Система ищёт в базе данных пользователя с таким email. |
| 3 | Решение (узел решения) | Если email найден → ошибка. Если не найден → регистрация продолжается. |
| 4 | Сохранение данных | Запись в БД со статусом «не подтверждён». |
| 5 | Параллельное выполнение | Одновременно отправляется письмо и запускается таймер. |
| 6 | Ожидание перехода | Пользователь должен перейти по ссылке из письма. |
| 7 | Проверка срока активации | Если переход произошёл в течение 24 часов → активация, иначе удаление. |
| 8 | Отображение результата | Сообщение об успешной регистрации или ошибке. |
## Пояснение к параллельным ветвям (fork/join)
В диаграмме используется конструкция **разветвления (fork)** и **слияния (join)**:
- **Разветвление** происходит после сохранения данных. Поток разделяется на два независимых параллельных процесса:
 - *Поток 1*: отправка письма с ссылкой для подтверждения
 - *Поток 2*: запуск таймера ожидания на 24 часа
- **Слияние** происходит перед узлом «Ожидать перехода по ссылке». Оба потока должны завершиться, прежде чем процесс продолжит выполнение.
Этот подход позволяет моделировать реальную ситуацию: письмо отправляется мгновенно, а таймер «тикнет» независимо, но основной процесс ждёт либо подтверждения, либо истечения времени.

## Диаграмма деятельности
```mermaid
graph TD
 Start([Начало]) --> A[Заполнить форму регистрации]
 A --> B[Ввести данные: имя, email, пароль]
 B --> C{Проверить уникальность email}
  
 C -->|Email уже существует| D[Показать сообщение об ошибке]
 D --> Finish1([Конец])
  
 C -->|Email свободен| E[Сохранить данные пользователя]
  
 E --> F1[Отправить письмо с ссылкой]
 E --> F2[Запустить таймер 24 часа]
  
 F1 --> G[Ждать перехода по ссылке]
 F2 --> G
  
 G --> H{Подтверждено в срок?}
  
 H -->|Да| I[Активировать аккаунт]
 I --> J[Отправить приветственное письмо]
 J --> K[Показать сообщение об успехе]
 K --> Finish2([Конец])
  
 H -->|Нет| L[Удалить неактивированную запись]
 L --> M[Уведомить о повторной регистрации]
 M --> Finish3([Конец])
