


> # Линейные алгоритмы: понятие, примеры и реализация
## 1. Определение линейного алгоритма
**Линейный алгоритм** — это алгоритм, в котором команды выполняются *последовательно, одна за другой*, в том порядке, в котором они записаны. Никакие шаги не пропускаются и не повторяются.
**Ключевые характеристики:**
- *Отсутствие ветвлений* (нет выбора между разными действиями).
- *Отсутствие циклов* (ни одно действие не повторяется).
- *Однонаправленное движение* от начала до конца.
> **Простая аналогия:** Линейный алгоритм похож на инструкцию по сборке стула, где вы строго идёте по пунктам: «Прикрутите ножку А», затем «Прикрутите ножку Б», затем «Прикрепите сиденье».
## 2. Примеры линейных алгоритмов
### 2.1. Вычисление арифметического выражения
**Задача:** Пользователь вводит два числа `a` и `b`. Программа вычисляет значение выражения {a + b}/{2}  (среднее арифметическое) и выводит результат.
**Реализация на Python:**
```python
# Ввод данных
a = float(input("Введите первое число: "))
b = float(input("Введите второе число: "))
# Обработка (линейный блок)
sum_ab = a + b
average = sum_ab / 2
# Вывод результата
print("Среднее арифметическое чисел", a, "и", b, "равно:", average)

**Пояснение:**

1.  **Ввод:** Команды `input()` считывают данные _последовательно_.
    
2.  **Вычисление:** Сначала находится сумма (`sum_ab`), затем результат делится на 2. _Важно:_ каждая операция выполняется в своём шаге.
    
3.  **Вывод:** Финальная команда отображает результат.
    

### 2.2. Обмен значениями двух переменных

**Задача:** Даны две переменные `x` и `y`. Поменять их значения местами (то есть после выполнения алгоритма в `x` должно быть старое значение `y`, и наоборот).

**Классическое решение (с использованием временной переменной):**

python

# Исходные данные
x = 5
y = 10
print("До обмена: x =", x, ", y =", y)
# Линейный алгоритм обмена
temp = x  # Шаг 1: сохраняем x во временную переменную
x = y     # Шаг 2: в x записываем y
y = temp  # Шаг 3: в y записываем сохранённое значение x
print("После обмена: x =", x, ", y =", y)

**Блок-схема алгоритма обмена:**

[https://./images/swap_diagram.png](https://./images/swap_diagram.png)

**Альтернативный способ в Python (без временной переменной):**

python

# "Магический" способ для Python (работает только в некоторых языках)
x, y = y, x

**Пояснение для классического способа:**

-   *Шаг 1 (temp = x)* — без этого шага оригинальное значение `x` будет потеряно при его перезаписи.
    
-   *Шаг 2 (x = y)* — теперь `x` содержит значение `y`.
    
-   *Шаг 3 (y = temp)* — `y` получает оригинальное значение `x`, которое было сохранено в `temp`.
    

## 3. Особенности реализации на языках программирования

При реализации линейных алгоритмов важно помнить о следующих особенностях:

-   **Последовательность критична.** Перестановка строк кода в линейном алгоритме меняет результат. Например, если поменять местами шаги 2 и 3 в алгоритме обмена, значения скопируются неверно.
    
-   **Типы данных.** При вычислениях следите за совместимостью типов. В Python деление `/` всегда возвращает `float`, даже если числа целые. Для целочисленного деления используется `//`.
    
-   **Ввод данных.** В реальных программах стоит добавлять _проверку ввода_, но она нарушит линейность (добавит ветвление). Строго линейный алгоритм предполагает, что данные корректны.
    
-   **Отсутствие «скачков».** В линейном алгоритме нет операторов `goto`, `break` (вне цикла), `return` (в середине функции) или исключений, меняющих поток выполнения.
