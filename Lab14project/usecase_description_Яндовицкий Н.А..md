# Диаграмма прецедентов: Интернет-магазин (кратко)
## 1. Предметная область
Интернет-магазин — система для покупки товаров онлайн. Покупатели ищут, выбирают, заказывают и оплачивают товары. Администратор управляет каталогом. Оплату обрабатывает внешняя платёжная система.
## 2. Акторы (3 шт.)
| Актор | Кто это |
|-------|---------|
| **Покупатель** | Обычный пользователь |
| **Администратор** | Управляет товарами, наследует всё от Покупателя |
| **Платёжная система** | Внешний сервис (банк) |
## 3. Прецеденты (7 шт.)
| Прецедент | Краткое описание |
|-----------|------------------|
| Поиск товаров | Найти товар по названию/цене |
| Добавить в корзину | Положить товар в корзину |
| Оформить заказ | Создать заказ |
| Оплатить заказ | Заплатить через платёжную систему |
| Управление каталогом | Добавлять/удалять/редактировать товары (только для администратора) |
| Авторизоваться | Войти в аккаунт |
| Использовать промокод | Ввести код скидки |
## 4. Отношения (обязательные элементы)
### Include (обязательное включение)
- **Оформить заказ** <<include>> **Авторизоваться** 
 *Нельзя оформить заказ без входа в аккаунт.*
### Extend (опциональное расширение)
- **Оплатить заказ** <<extend>> **Использовать промокод** 
 *Можно оплатить со скидкой, а можно и без.*
### Generalization (наследование акторов)
- **Администратор** наследует **Покупателя** 
 *Администратор умеет всё, что и покупатель + управление каталогом.*
## 5. Кто с чем связан
| Актор | Какие прецеденты использует |
|-------|----------------------------|
| Покупатель | Поиск, Добавить в корзину, Оформить заказ, Оплатить, Авторизоваться, Использовать промокод |
| Администратор | Всё из Покупателя + Управление каталогом |
| Платёжная система | Только Оплатить заказ |
