## 🔍 О проекте
**PassGenius** — это **кросс-платформенный** генератор паролей, работающий в терминале и как `Python-библиотека`. 
Проект создан для тех, кто устал от *ненадёжных комбинаций* вроде `qwerty123` или `password`. Главная цель — дать пользователю возможность генерировать **криптостойкие пароли** с минимальными усилиями, а также **проверить их безопасность** в реальном времени.
> *«Единственный по-настоящему надёжный пароль — это тот, который вы не можете запомнить и вынуждены хранить в менеджере паролей.»* 
> — Лори Крамер, эксперт по кибербезопасности [¹](#footnote1)
### 🔐 Ключевые преимущества
- **Высокая энтропия** — каждый пароль генерируется с использованием криптостойкого ГСЧ (`secrets` в Python)
- **Мгновенная проверка** — интеграция с API Have I Been Pwned (без передачи самого пароля)
- **Полная прозрачность** — код с открытым исходным кодом, никаких телеметрий и сбора данных

## ✨ Возможности
- 🎲 **Гибкая генерация**
 - Длина пароля: от 8 до 128 символов
 - Настройка наборов символов
 - Исключение похожих символов (`1`, `l`, `I`, `O`, `0`)
  
- 📋 **Удобство использования**
 - Автоматическое копирование в буфер обмена
 - Сохранение истории генерации (опционально)
 - Экспорт в JSON / CSV
- 🧪 **Анализ безопасности**
 - Расчёт энтропии по Шеннону
 - Проверка времени взлома (brute-force estimate)
 - Валидация пароля по 20+ правилам сложности
- 🔍 **Анти-утечки**
 - Анонимная проверка через HIBP (k-anonymity)
 - Локальный кэш проверенных паролей

 ```bash

    bash

6.  **Проверьте установку**
    
    bash
    
    passgenius --version  # Должно вывести 2.0.0

## 💻 Пример использования

Ниже показан пример генерации пароля с проверкой утечек:

python

# Пример кода: генерация пароля с энтропией > 80 бит
from passgenius import Generator, HibpChecker
# Создаём генератор с параметрами
gen = Generator(
 length=16,
 use_uppercase=True,
 use_lowercase=True,
 use_digits=True,
 use_special=True,
 exclude_ambiguous=True
)
# Генерируем пароль
password = gen.generate()
entropy = gen.calculate_entropy(password)
print(f"🔑 Пароль: {password}")
print(f"📊 Энтропия: {entropy:.1f} бит")
print(f"⏱️  Время взлома перебором: {gen.crack_time(entropy)}")
# Проверка утечек
checker = HibpChecker()
if checker.is_pwned(password):
 print("⚠️ ВНИМАНИЕ: Этот пароль найден в утечках данных!")
else:
 print("✅ Пароль чист — не обнаружен в компрометированных базах.")

**Пример вывода:**
